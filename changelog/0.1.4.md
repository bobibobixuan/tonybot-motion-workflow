# 0.1.4 - 2026-05-12

## Added

- 新增 `rob_library.py`，提供三类动作库逆向入口：
  - `analyze`：批量解析 `.rob`，生成库级字段统计和异常报告。
  - `export-json`：把每个动作导出为结构化 JSON，包含帧时长、帧头、16 个有效槽位和 filler 校验结果。
  - `decrypt-eypt`：把 `EYPT` 保护动作解密为明文 `ACT-40`，输出到独立目录，不覆盖原始动作库。
- 生成 `动作库解析报告.json`，记录当前动作库 204 个 `.rob`、5386 帧、4 个 `EYPT` 样本的完整统计。
- 生成 `动作库解析/`，导出 204 个逐动作 JSON。
- 生成 `动作库解密/`，导出 4 个 `EYPT` 明文动作。

## Reverse Engineering

- 确认当前动作库中所有 5386 帧的帧标记均为 `0x5555`。
- 确认当前动作库中所有 5386 帧的两个帧头保留字段均为 `0x0000`。
- 确认当前动作库没有发现 filler 区异常。
- 确认第 2、第 3 字段在当前动作库中成对出现：15024 个槽位同时非零，没有只出现其中一个字段的槽位。
