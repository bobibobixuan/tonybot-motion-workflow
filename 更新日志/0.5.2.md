# 0.5.2 — 3D 动作预览器规范化

## 变更

- **预览器正式命名**：`动作模拟器.html` 定位为「Tonybot 3D 动作预览器 / Motion Viewer」，标题改为「Tonybot 3D 动作预览器」。
- **新增复制 Pose 按钮**：顶部 📋 按钮，一键复制当前 16 舵机值为 `[500,387,…]` JSON 数组。
- **新增帧信息条**：顶部显示总帧数、当前已播时长 / 总时长（分:秒格式）。
- **新增帧跳变提示区**：加载 `.rob` 后自动扫描相邻帧舵机值变化，超过 200 阈值时在底部提示，仅列出 ID 和变化量，不输出安全结论。
- **更新控制台日志**：启动信息和提示文字同步更新。
- **新增规范文档**：`python-toolkit/文档/11-3D动作预览器规范.md`，含模块定位、输入格式、舵机映射、UI 清单、禁止事项、验证流程、与 rob_safety 关系。
- **新增模拟器 README**：`python-toolkit/可视化模拟器/README.md`，说明打开方式、CDN 依赖、拖拽支持和定位声明。
- **更新根 README**：删除 COM/支撑面/平衡仪表表述，明确预览器仅做 FK 姿态预览。
- **更新文档索引**：`python-toolkit/文档/README.md` 阅读顺序追加第 11 项。

## 原因

将预览器与安全审计彻底解耦——预览器是可视化工具体验，安全结论由 `rob_safety.py` 和 `dance_workflow.py build` 流程负责。
