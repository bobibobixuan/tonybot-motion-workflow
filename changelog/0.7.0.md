# 0.7.0 — 主线重构：Tonybot Action Simulator

## 变更

- **项目重新定位**：从「Tonybot Motion Studio / AI 辅助动作创作工作台」收敛为「Tonybot Action Simulator / 动作模拟器」。
- **新主入口**：`simulator/index.html`，基于 Three.js 的 3D FK 骨骼姿态预览器。
  - 新增 i18n 国际化支持：`simulator/i18n/zh-CN.json` 和 `en-US.json`。
  - 默认语言 zh-CN，文本通过 key 驱动，不再硬编码中文。
  - 新增 `simulator/README.md`。
- **新数据层**：`data/official-actions/`。
  - `index.json`：204 个官方动作组索引。
  - `categories.json`：分类统计。
  - `schema.md`：数据结构说明。
  - `actions/*.json`：逐动作完整数据（id/name/frames/pose 等）。
- **工具集中化**：`tools/python/`。
  - 复制 rob_reverse.py、rob_crypto.py、rob_library.py、rob_safety.py、rob_compose.py、dance_workflow.py、tonybot_physics.py、main.py。
  - rob_library.py 路径去中文依赖，WORKSPACE_ROOT 指向仓库根目录。
  - rob_library.py 新增 `export-official-actions` 命令，自动分类、生成 slug、输出 JSON。
- **知识迁移**：`knowledge/docs/`（原 python-toolkit/文档/）、`knowledge/wondercode/`（原 wondercode-toolkit/）。
- **历史归档**：`legacy/choreography/`（原编舞 JSON + 动作模块）、`legacy/motion-studio/`（Motion Studio 架构规划）。
- **更新日志迁移**：`更新日志/` → `changelog/`（git mv 保留历史）。
- **旧目录保留**：`python-toolkit/` 和 `wondercode-toolkit/` 完整保留，未删除任何文件。

## 未改动

- 未删除原始 .rob 动作文件。
- 未破坏 ACT-40 / EYPT 解析逻辑。
- 未重新加入 COM、支撑面、平衡分。
- 未引入 React/Vite 等前端框架。
- 未实现 AI 编舞。
