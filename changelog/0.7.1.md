# 0.7.1 — 舵机映射建模细化

## 变更

- 新增 `data/servo-map.json`，把 16 个舵机统一建模为 `id/channel/joint/label_zh/label_en/axis_type/motion_zh/confidence/needs_calibration`。
- 明确 `axis_type` 枚举，区分 `yaw_vertical`、`pitch_lateral`、`roll_longitudinal` 和两类待实测轴。
- 保留 `ID1` / `ID9` 为 `r_hip_yaw` / `l_hip_yaw`，不直接写成 `foot_yaw`。
- 保留 `ID2` / `ID10` 为 `r_ankle_axis` / `l_ankle_axis`，轴向标记为 `unknown_pitch_or_roll`。
- 保留 `ID7` / `ID15` 为 `r_shoulder_axis_2` / `l_shoulder_axis_2`，轴向标记为 `unknown_yaw_or_roll`。
- 新增 `knowledge/docs/14-servo-layout.md`，说明舵机布局建模原则、三类主轴向和单舵机小幅实测确认要求。
- 更新 `knowledge/docs/12-motion-json格式规范.md`、`knowledge/docs/13-3D动作预览器规范.md` 和 `knowledge/docs/README.md`，同步新映射与 `pose[0]..pose[15]` 固定顺序。
- 更新 `simulator/index.html` 与 `simulator/i18n/*.json` 的通道标签和内部 joint 命名；肩部第二轴在当前 FK 中仍只作临时预览近似，不宣称已确认是 roll。

## 未改动

- 未改变 `pose[0]..pose[15]` 的顺序。
- 未修改 `.rob` / `ACT-40` / `EYPT` 解析逻辑。
- 未重新加入 COM、支撑面或平衡分。

## 验证

- `pwsh -NoLogo -Command "Get-Content -Raw -Encoding UTF8 data/servo-map.json | ConvertFrom-Json | Out-Null; Get-Content -Raw -Encoding UTF8 simulator/i18n/zh-CN.json | ConvertFrom-Json | Out-Null; Get-Content -Raw -Encoding UTF8 simulator/i18n/en-US.json | ConvertFrom-Json | Out-Null"`
