# 06 验证与发布

## 必做验证

改动 Python 脚本后至少执行：

```powershell
uv run python -m py_compile rob_reverse.py rob_crypto.py rob_compose.py rob_safety.py dance_workflow.py main.py
```

改动 `rob_crypto.py`、`rob_reverse.py` 或逆向结论后，必须验证官方 `EYPT` 样本往返一致：

```powershell
uv run python -c "import pathlib, rob_crypto; files=[p for p in pathlib.Path('动作').glob('*.rob') if p.read_bytes()[8:12]==b'EYPT']; failed=[p.name for p in files if rob_crypto.encrypt_action_bytes(rob_crypto.decrypt_action_bytes(p.read_bytes())) != p.read_bytes()]; print('eypt_files=', len(files)); print('failed=', failed); raise SystemExit(0 if len(files)==4 and not failed else 1)"
```

改动动作、编舞或安全规则后至少执行：

```powershell
uv run python rob_safety.py "动作\159号自制舞蹈.rob"
```

## 合格标准

1. Python 语法检查通过。
2. `EYPT` 样本往返无差异。
3. 安全审计结果 `violations=0`。

## 版本规则

任何功能、文档、资源或规则更新，都要同步：

1. 更新 `VERSION`。
2. 更新 `CHANGELOG.md`。
3. 在 `更新日志/` 下新增对应版本条目。

默认版本策略：

1. patch：常规修订、文档更新、局部规则补充。
2. minor：较大功能扩展或流程升级。
3. major：仅在用户明确要求时提升。

## Windows 注意事项

1. 读取中文 UTF-8 文件时显式使用 `-Encoding UTF8`。
2. 避免用会破坏编码的 ANSI 路径处理 JSON 和 Markdown。
3. 如遇文件属性异常，使用 `ReadAllBytes` + `WriteAllBytes` 原地重写正式路径。

## 发布建议

发版时优先确认：

1. 核心脚本语法通过。
2. 关键编舞样本仍可重建。
3. 重要安全规则变更已反映到专题文档与根文档。
