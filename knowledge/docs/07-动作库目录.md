## 使用指南

### 编舞时查找动作

1. **先查本目录** → 确定需要的动作类别（基础/移动/拳击/踢腿/表演...）
2. **优先用预设模块 (301-350)** → 语义化命名，经过安全审计
3. **需要精细控制时用手写模块 (351-400)** → 显式舵机角度，可独立使用
4. **特殊需求时直接用官方原始动作 (0-104)** → 通过 `source` 字段引用文件名

### 安全回正规范

所有编舞的前后应注入保护段：

- `302号快速回正` → `0号立正`（开场自动回正）
- `302号快速回正` → `0号立正`（收尾稳定站立）

通过 `guards.pre_segments` / `guards.post_segments` 配置，不混入 `segments` 主体。
