# 03 安全模型与约束

## 安全模型定位

当前安全模型已从单层“统计包络”升级为双层模型：

1. 统计包络层。
2. 控制语义 + 运动学/硬件约束层。

## 统计包络层

统计层仍负责最基础的边界控制：

1. 字段最小值和最大值范围。
2. 单关节逐帧最大跳变。
3. 总姿态 `L1` 跳变。
4. 动作时长与节拍落点的基础一致性。

## 控制语义层

语义层的目标是拦截“数值没越界，但动作逻辑不合理”的情况，当前包括：

1. 基于官方动作库建立语义锚点。
2. 学习语义状态半径与允许迁移集合。
3. 检查高负载姿态前后的准备态和回收态。
4. 限制危险状态的最小时长和硬切换。

## 编舞硬规则

当前必须遵守的规范：

1. 默认优先复用官方动作段和已审计模块。
2. 自定义帧必须落在官方样本包络内。
3. 输出 `.rob` 前必须跑 `rob_safety.py`。
4. 完整展示类舞蹈默认前后都要回正。

## 回正规范

回正不是单支舞的临时补丁，而是编舞规范的一部分：

1. 开场前应插入回正保护段，确保从未知姿态回到稳定站姿。
2. 收尾后应插入回正保护段，确保动作结束后回到可接续状态。
3. 当前推荐组合是 `302号快速回正.rob -> 0号立正.rob`。
4. 编舞 JSON 应通过顶层 `guards.pre_segments` / `guards.post_segments` 注入，而不是把回正散落在主体拍点里。
