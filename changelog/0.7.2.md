# 0.7.2 — 分层单轴 FK 骨架

## 变更

- `simulator/index.html` 的 3D FK 骨架从简化万向近似升级为 `THREE.Group` 分层单轴关节骨架。
- 右腿改为 `rightHipYawPivot -> rightHipRollPivot -> rightHipPitchPivot -> rightKneePivot -> rightAnklePivot`。
- 左腿改为 `leftHipYawPivot -> leftHipRollPivot -> leftHipPitchPivot -> leftKneePivot -> leftAnklePivot`。
- 右臂改为 `rightShoulderAxis1Pivot -> rightShoulderAxis2Pivot -> rightElbowPivot`。
- 左臂改为 `leftShoulderAxis1Pivot -> leftShoulderAxis2Pivot -> leftElbowPivot`。
- `updateRobotModel` 现在只更新 pivot 旋转，不再直接对肢体 mesh 做多轴乱转。
- `ID2/ID10`、`ID7/ID15` 在代码注释中明确保留“待实测确认”，当前只做临时单轴渲染。
- 舵机模块随对应关节层级挂载，`ID1/ID9` 的视觉位置从脚部语义纠正为髋部 yaw 层级。

## 未改动

- 未改变 `.rob` 解析逻辑。
- 未改变 `pose[0]..pose[15]` 顺序。
- 未重新加入 COM、支撑面、平衡分或安全结论。
