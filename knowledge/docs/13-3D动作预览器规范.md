# 13 — Tonybot 3D 动作预览器规范

## a. 模块定位

| 项目 | 说明 |
|------|------|
| 正式名称 | **Tonybot 3D 动作预览器（Motion Viewer）** |
| 文件位置 | `python-toolkit/可视化模拟器/动作模拟器.html` |
| 核心职责 | 3D FK 骨骼姿态预览、`.rob` 加载、帧播放、16 舵机滑块调试 |
| 运行环境 | 现代浏览器（Chrome / Edge / Firefox），需网络加载 Three.js CDN |
| 依赖 | Three.js 0.160.0（ESM import from unpkg CDN） |

预览器是**纯视觉预览工具**，不替代也不参与安全审计流程。

## b. 输入文件格式

预览器支持两种 `.rob` 文件格式：

1. **明文 ACT-40**：文件头 magic `ACT-40`，数据区直接包含帧数组。
2. **加密 EYPT**：文件头 magic `ACT-40`，tag 字段为 `EYPT`。预览器内置 TEA-32 解密引擎（密钥见 `rob_crypto.py` 的 `ENCRYPT_ARRAY`），解密后按明文帧解析。

文件结构：

```
[16 字节文件头] + [frame_count × 248 字节帧区]
```

文件头解析：

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 6 | magic | 固定 `ACT-40` |
| 6 | 2 | frame_count | uint16 LE，帧数 |
| 8 | 4 | tag | `EYPT`（加密）或 `\0\0\0\0`（明文） |

解密范围：`data[16:]`（文件头不参与 TEA）。

## c. 帧数据结构

单帧 = 248 字节，解析规则：

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 2 | duration | uint16 LE，本帧持续时长（ms） |
| 2 | 6 | _reserved_ | 帧头保留，不用于预览 |
| 8 | 240 | channel_data | 40 通道 × 3 字（每字 2 字节 uint16 LE） |

有效舵机通道：前 **16 个槽位**（channel 0–15），后 24 个槽位为 filler（`0x5555 0x0000 0x0000`）。预览器只读取前 16 通道的第一个字作为舵机值，范围 0–1000。

输入帧数据格式（JavaScript 解析后）：

```js
{
  duration: 500,       // 本帧时长 ms
  pose: [500, 387, …], // 16 个 uint16，对应 ID1–ID16
}
```

## f. 禁止事项

以下功能**不得**重新加入预览器：

1. ❌ 安全评分（balance score / 0–100 平衡分）
2. ❌ COM 质心可视化（红球 + 地面投影虚线）
3. ❌ 支撑多边形可视化（绿色半透明面 + 边框）
4. ❌ 安全审计结论（violations、danger、safe 等标签）
5. ❌ 平衡仪表 UI（`bal-status`、`bal-score` 等 DOM 元素）
6. ❌ 物理层切换按钮（⚖️ toggle physics）
7. ❌ 双脚地面指示环（`rFootRing`、`lFootRing`）

帧跳变提示**只列出**变化过大的舵机 ID 和变化量，不得附带"可能不安全""建议调整"等任何安全判断语句。

预览器输出的 `copy Pose` 结果**仅是** 16 个整数数组，**不是**安全审计结论。

## g. 验证流程

每次修改预览器 HTML 后，执行以下检查：

1. 双击 `动作模拟器.html` 在浏览器打开，确认页面正常渲染。
2. 打开浏览器控制台（F12），确认无红色 JS 报错。
3. 拖动任意舵机滑块，确认 3D 骨骼实时响应。
4. 点击预设姿态按钮（立正/军礼/…），确认姿态正常切换。
5. 拖拽一个 `.rob` 文件到视口，确认加载成功、帧数显示正确。
6. 点击播放按钮，确认帧循环播放正常。
7. 点击 📋 复制 Pose，粘贴到记事本，确认得到 16 个整数。
8. 检查帧跳变提示区在加载后是否正常显示（如有超阈值跳变）。
9. 确认顶部标题为「Tonybot 3D 动作预览器」。
10. 确认页面上没有任何安全评分、COM、支撑面或平衡相关元素。

## h. 与 rob_safety.py 的关系

| 项目 | 动作预览器 | rob_safety.py |
|------|-----------|---------------|
| 定位 | 可视化预览工具 | 命令行安全审计工具 |
| 输入 | `.rob` 文件（拖拽/按钮） | `.rob` 文件（命令行参数） |
| 输出 | 3D 骨骼动画 | violations 计数 + 审计报告 |
| COM 计算 | ❌ 不做 | ✅ 用于支撑面判断 |
| 安全结论 | ❌ 不给出 | ✅ 给出 PASS/FAIL |
| 使用场景 | 编舞过程中快速预览姿态 | 构建后自动审计、CI 验证 |

两者的关系是**互补而非替代**：

- 编舞过程中用**预览器**快速检查姿态是否自然。
- 构建后用 `dance_workflow.py build` + `rob_safety.py` 做正式安全审计。
- 预览器的"帧跳变提示"仅辅助发现可疑帧切换，**不是安全审计**。
