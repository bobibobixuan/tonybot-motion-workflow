# 队列安全动作分组

本页用于给 **多人同跳、脚不平移、队形不互撞** 的场景挑动作。

目标不是“单机最好看”，而是：

1. 多台机器人并排站时不会互相横移或前后撞上。
2. 动作重心稳定，不容易因为单脚支撑或大开大合摔倒。
3. 适合工业校歌、广播体操、升旗仪式、展示队列这类场景。

## 一、禁用动作

以下动作默认 **不要** 用于多人并排队列表演：

### 1. 明显位移动作

- `1号前进`
- `2号后退`
- `11号左侧滑`
- `12号右侧滑`
- `21号循环前进`
- `22号循环后退`
- `23号左转(原地)`
- `24号右转(原地)`
- `34号左转(前进)`
- `35号右转(前进)`
- `36号左转过渡`
- `37号右转过渡`
- `71号向前走俩步`
- `72号后退俩步`
- `73号向左转7步`
- `74号右转7步`
- `75号原地左转90°`
- `76号原地右转`

对应预设模块默认禁用：

- `309号左侧滑短句`
- `310号右侧滑短句`
- `311号左右侧滑往返`
- `322号前进拳击`
- `342号前行两步`
- `343号后退两步`
- `344号左转七步`
- `345号右转七步`
- `346号左转九十`
- `347号右转九十`
- `350号头顶携带前进一步`

### 2. 已知高风险失稳动作

- `17号大鹏展翅`
- `326号大鹏展翅`

原因：

1. 开展幅度大。
2. 重心切换明显。
3. 真机试验里已经出现摔倒风险。

这两个动作在“队列表演版”里应视为 **黑名单**。

4. 前后必须接回正或稳定站姿。

## 三、推荐动作

以下动作优先用于 **广播体操感、整齐感、脚不平移** 的版本：

### A 组：稳定站姿/礼仪

- `0号立正`
- `19号快速立正`
- `10号鞠躬`
- `301号站姿基座`
- `302号快速回正`
- `303号礼貌鞠躬`
- `384号手写浅礼起身`
- `386号手写礼后回正`

### B 组：上肢展示/开合

- `9号挥手`
- `27号伸右手`
- `48号介绍动作`
- `304号招手问候`
- `305号展示姿态`
- `328号伸右手`
- `391号手写开场点头`
- `392号手写展肩亮相`

### C 组：广播体操式节拍动作

- `325号捶胸强调`
- `327号抱娃娃`
- `390号手写低位回正`
- `361号手写左扭腰入拍`
- `362号手写右扭腰入拍`
- `363号手写左右扭腰往返`
- `364号手写左扭腰双击`
- `365号手写右扭腰双击`
- `370号手写左右交替拳`

这些动作的共同点：

1. 以双脚站位固定为主。
2. 主要表达来自上肢、肩胸、头部和轻微躯干变化。
3. 更适合“多人一起做整齐广播操”的视觉风格。

## 四、队列表演编舞规则

当目标是“多台机器人一起跳舞会和谐，不会撞在一起”时，默认采用下面规则：

1. 禁用全部位移、转向、侧滑动作。
2. 禁用 `17号/326号大鹏展翅`。
3. 主体动作优先从 `304/305/325/327/328/361-365/370/389/390/391/392` 中选。
4. 开头固定插入 `302号快速回正 + 0号立正`。
5. 结尾固定插入 `303号礼貌鞠躬 + 386号手写礼后回正 + 302号快速回正 + 0号立正`。
6. 若必须加入踏步，只能短句点缀，不可作为整舞主干。
7. 多人排练时默认按“肩同宽站位 + 不跨步”设计，不指望靠现场临时避让。

- `362号手写右扭腰入拍`
- `363号手写左右扭腰往返`
- `364号手写左扭腰双击`
- `365号手写右扭腰双击`
- `370号手写左右交替拳`
- `390号手写低位回正`
- `391号手写开场点头`
- `303号礼貌鞠躬`
- `386号手写礼后回正`

这套选型的视觉目标是：

1. 像广播体操一样整齐。
2. 像学校展演一样庄重。
3. 保留工业校歌的机械感和口号感。
4. 让多台机器人同时跳时整体更和谐。
