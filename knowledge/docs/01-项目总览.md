# 01 项目总览

## 项目定位

Tonybot Motion Workflow 是一个围绕 Tonybot `.rob` 动作文件建立的工程仓库，目标不是做通用机器人控制平台，而是把“动作逆向、动作复用、安全编舞、产物生成”做成可复现流程。

当前核心目标：

1. 解析 `.rob` / `ACT-40` 动作容器。
2. 独立复现 `EYPT` 保护层的 `TEA-32` 加解密。
3. 基于官方动作库做安全编舞、审计和生成。
4. 把编舞 JSON 编译成 `.rob`、审计报告和时间线 HTML。

## 已具备能力

1. 可解析官方 `.rob` 文件并导出结构化 JSON。
2. 可对 `EYPT` 样本做独立解密和逐字节重加密校验。
3. 可从官方动作库学习安全边界并对新动作做自动审计。
4. 可基于编舞 JSON 生成 `.rob`、报告 JSON 和时间线 HTML。

## 当前边界

以下内容不能被误判为已经彻底完成：

1. 有效槽位第 2、第 3 个 16 位字段的精确物理语义仍未完全确认。
2. 设备端是否还有依赖帧头保留字段的隐藏逻辑仍未完全排除。
3. 任意手写舵机轨迹不能默认视为绝对硬件安全。

## 目录视角

关键目录和文件：

1. `动作/`：官方动作、解密样本和生成产物。
2. `编舞/`：编舞 JSON、报告 JSON、时间线 HTML。
3. `动作模块/`：可复用动作短句、保护段和手写模块。
4. `rob_reverse.py`：动作容器解析。
5. `rob_crypto.py`：`EYPT/TEA-32` 加解密。
6. `rob_safety.py`：安全审计。
7. `rob_compose.py`：动作拼接与输出。
8. `dance_workflow.py`：编舞工作流入口。
9. `main.py`：设备端控制逻辑。
