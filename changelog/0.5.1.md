# 0.5.1 — 3D 模拟器去审计化

## 变更

- **定位调整**：`动作模拟器.html` 从「FK 模拟器 + 物理审计器」改为「纯 FK 骨骼姿态预览器」。
- **删除的安全审计模块**：
  - 顶部平衡分显示（`bal-score`、`bal-status`、平衡仪表）
  - 物理层切换按钮（⚖️）
  - COM 质心红球 + 地面投影虚线
  - 绿色半透明支撑多边形 + 边框
  - 双脚地面指示环（红/蓝 torus）
  - `updatePhysicsLayer()` 函数（~50行）
  - `updateBalanceUI()` 函数（~30行）
  - `physicsGroup` 及全部子对象（`comSphere`、`comLine`、`supportMesh`、`supportLine`、`feetGroup`、`rFootRing`、`lFootRing`）
  - `showPhysics` 变量
  - CSS `#balance-indicator` 样式块
- **保留的全部预览功能**：
  - Three.js 3D 骨骼渲染 + OrbitControls
  - 16 舵机滑块面板（按右臂/左臂/右腿/左腿分组）
  - `.rob` 加载（ACT-40 + EYPT TEA-32 解密）
  - 帧时间轴 + 上一帧/下一帧/播放/暂停/速度倍率
  - 7 组预设姿态
  - FK 姿态计算（内部保留，仅用于驱动骨骼）
  - 脚底铁片平行地面渲染逻辑
  - 舵机编号标签切换
- 标题改为「🤖 Tonybot 3D 动作预览器 · 无安全审计版」，副标题「仅骨骼姿态预览，不输出平衡/安全结论」。

## 原因

关节限位、真实髋部结构、支撑脚锁定、根节点位移尚未完全校准，当前安全审计结论不可靠。移除审计避免误导。
