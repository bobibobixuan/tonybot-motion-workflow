# Tonybot 完整积木指令映射

本页基于官方积木转换工具导出的 Python 结果整理。所有示例均以 **导出代码实际长相** 为准。

## 初始化

```python
import Hiwonder
import time
import Hiwonder_IIC
from Hiwonder_BLE import BLE

tonybot = Hiwonder.Tonybot()
beep = Hiwonder.Buzzer()
i2c = Hiwonder_IIC.IIC()
imu = Hiwonder_IIC.MPU()
ble = BLE(BLE.MODE_BLE_SLAVE, "Tonybot")
uart = Hiwonder.UART(9600, 2, 5)
```

## 主程序与动作控制

| 积木指令 | Python |
|---|---|
| Tonybot 主程序 | `Hiwonder.startMain(start_main)` |
| 使能头部舵机 | `tonybot.attachHead()` |
| 失能头部舵机 | `tonybot.detachHead()` |
| 控制头部舵机角度 90 | `tonybot.moveHeadAngle(90)` |
| 控制机体总线舵机 1 位置 500 时长 100ms | `tonybot.moveServo(1, 500, 100)` |
| 运行动作组编号 1 次数 1 | `tonybot.runActionGroup(1, 1)` |
| 停止动作组运行 | `tonybot.stopActionGroup()` |
| 设置动作组 1 运行速度 100% | `tonybot.setActionGroupSpeed(1, 100)` |
| 设置所有动作组运行速度 100% | `tonybot.setAllActionGroupSpeed(100)` |
| 运行动作组编号 是否正在运行？ 次数 1 | `tonybot.runActionGroup(tonybot.isRunning(), 1)` |
| 是否正在运行 | `tonybot.isRunning()` |
| 等待运行结束，超时时间 100ms | `tonybot.waitForStop(100)` |
| 电池电压 (mV) | `tonybot.getBatteryVolt(100)` |

## 流程控制

下面这组映射来自你补充的“Tonybot主程序 + 控制流积木”导出结果：

```python
time.sleep(1)
time.sleep(time.ticks_ms())
for count in range(10):
    pass
while True:
    if False:
        if False:
            while not False:
                pass
            while not False:
                break
        else:
            return
```

| 积木指令 | Python |
|---|---|
| 等待 1 秒 | `time.sleep(1)` |
| 获取系统时间(ms) | `time.ticks_ms()` |
| 等待 获取系统时间(ms) 秒 | `time.sleep(time.ticks_ms())` |
| 重复执行 10 次 | `for count in range(10):` |
| 重复执行 | `while True:` |
| 如果 条件 那么 | `if <condition>:` |
| 否则 | `else:` |
| 等待直到 条件 | `while not <condition>:` |
| 重复执行直到 条件 | `while not <condition>:` |
| 结束循环 | `break` |
| 返回 | `return` |

> 这个导出结果有两个值得单独记下的点：
>
> 1. “重复执行”会直接导出成 `while True:`。
> 2. 当前样例里“等待直到 条件”与“重复执行直到 条件”都表现为 `while not <condition>:`，区别要结合积木嵌套位置判断。

## 蜂鸣器与 IMU

| 积木指令 | Python |
|---|---|
| 播放音调为 65 节拍为 500 模式为后台播放 | `beep.playTone(65, 500, False)` |
| 蜂鸣器设置音量大小 100 | `beep.setVolume(100)` |
| 获取陀螺仪 GyX 值 | `imu.read_gyro_data()[0]` |
| 获取 IMU 传感器翻滚角 ROLL 值 | `imu.read_angle()[0]` |
| 蜂鸣器设置音量大小 获取陀螺仪 GyX 值 | `beep.setVolume(imu.read_gyro_data()[0])` |
| 蜂鸣器设置音量大小 获取 IMU 传感器翻滚角 ROLL 值 | `beep.setVolume(imu.read_angle()[0])` |

> 当前样例里“播放音调为 C2 / 二分之一拍”最终同样落成 `beep.playTone(65, 500, False)`。这说明积木层的音名和节拍会先被官方工具折算成数值参数。

## 蓝牙

| 积木指令 | Python |
|---|---|
| 设置蓝牙为从机模式，名称 Tonybot | `ble = BLE(BLE.MODE_BLE_SLAVE, "Tonybot")` |
| 蓝牙发送数据 CMD | `ble.send_data("CMD")` |
| 解析蓝牙数据 0，获取命令 | `ble.parse_uart_cmd("0")[0]` |
| 解析蓝牙数据 0，获取参数 1 | `ble.parse_uart_cmd("0")[1]` |
| 蓝牙发送数据 解析蓝牙数据 0，获取命令 | `ble.send_data(ble.parse_uart_cmd("0")[0])` |
| 蓝牙发送数据 解析蓝牙数据 0，获取参数 1 | `ble.send_data(ble.parse_uart_cmd("0")[1])` |

下面这些积木在你这次给出的导出样例里没有实际调用，但仍建议后续继续用“导出后登记”的方式补齐：

- 蓝牙已连接？
- 获取蓝牙 MAC 地址
- 蓝牙接收数据遇到结束标
- 获取接收到的蓝牙数据

## 串口 UART

当前示例固定初始化为：

```python
uart = Hiwonder.UART(9600, 2, 5)
```

映射如下：

| 积木指令 | Python |
|---|---|
| 初始化串口接口 IO2-IO5 波特率 9600 | `Hiwonder.UART(9600, 2, 5)` |
| 串口发送数据 CMD | `uart.send_data("CMD")` |
| 串口有接收到数据？ | `uart.has_data()` |
| 串口接收到数据包含 CMD ? | `uart.contains_data("CMD")` |
| 串口接收缓存 | `uart.read_buffer()` |
| 获取串口指令 | `uart.read_uart_cmd()` |
| 解析串口接收数据 0 获取参数 1 | `uart.parse_uart_cmd("0")[1]` |
| 解析串口接收数据 0 获取指令 | `uart.parse_uart_cmd("0")[0]` |
| 清空接收缓存 | `uart.clear_buffer()` |

在主程序里这些值被直接作为发送参数再次发送：

```python
uart.send_data(uart.has_data())
uart.send_data(uart.contains_data("CMD"))
uart.send_data(uart.read_buffer())
uart.send_data(uart.read_uart_cmd())
uart.send_data(uart.parse_uart_cmd("0")[1])
uart.send_data(uart.parse_uart_cmd("0")[0])
```
