# 14 舵机布局与关节映射

本文档是 Tonybot 16 路舵机的**当前权威映射说明**。  
数据文件以 `data/servo-map.json` 为准，本文负责解释这些字段为什么这样命名、页面如何使用它们、哪些方向已经确认。

## 一、本文回答什么

本文只回答四件事：

1. `pose[0]..pose[15]` 固定对应哪一个 `ID`。
2. 每个 `ID` 对应机器人身体上的哪个关节轴。
3. 站立值是多少、镜像轴是谁。
4. 单舵机实测后，哪些“增大/减小 -> 动作结果”已经确认。

本文**不**负责：

1. `.rob` 二进制文件结构
2. 动作安全结论
3. 质心或支撑面判断
4. “脚尖上翘还是下压”这类仍需按真机重心效果微调的细节

## 二、固定顺序

`pose[0]..pose[15]` 的顺序是锁定的：

```text
pose[0]  = ID1
pose[1]  = ID2
...
pose[15] = ID16
```

任何代码、文档或网页都**不能**为了“看起来更直观”而重排这个顺序。

## 三、身体分区

最简单的记法是：

```text
ID1～ID5   = 右腿
ID6～ID8   = 右臂
ID9～ID13  = 左腿
ID14～ID16 = 左臂
```

层级关系：

```text
右腿：ID1 -> ID5 -> ID4 -> ID3 -> ID2
左腿：ID9 -> ID13 -> ID12 -> ID11 -> ID10

右臂：ID8 -> ID7 -> ID6
左臂：ID16 -> ID15 -> ID14
```

## 七、尚保留的保守口径

以下内容仍不在文档中写死：

1. `ID1` / `ID9` 增大到底是“内旋”还是“外旋”。
2. `ID2` / `ID10` 增大到底是“脚尖上翘”还是“脚掌下压”。

原因不是关节类别不清楚，而是这些细节更适合在步态调试时按**真实重心效果**微调。

## 九、模拟器如何使用这套映射

当前网页模拟器做法如下：

1. `simulator/js/config.js` 以 16 个舵机对象描述 `id/channel/joint/neutral/direction/group/mirror_id`。
2. `simulator/js/robot-scene.js` 用同一套 `joint` 名称驱动 3D 舵机层级。
3. `simulator/js/simulator-app.js` 左栏渲染当前舵机详情、镜像对照和 16 路速查卡片。
4. `data/servo-map.json` 保存文档级权威映射数据，供页面与说明文档交叉核对。

## 十、维护规则

如果以后又做了新的单舵机测试，更新顺序必须是：

1. 先改 `data/servo-map.json`
2. 再改 `simulator/js/config.js`
3. 再改 `knowledge/docs/14-servo-layout.md`
4. 最后检查 `simulator/index.html` 页面显示是否一致
