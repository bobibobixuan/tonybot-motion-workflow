# 0.5.0 — Tonybot 3D FK 动作模拟器

## 新增

- **`可视化模拟器/动作模拟器.html`**：自包含 3D FK 动作模拟器，双击即开。
  - Three.js 0.160 CDN 渲染 Tonybot 简化 3D 骨骼模型（圆柱体四肢 + 球体关节 + 方块躯干/脚部）。
  - 完整翻译 `tonybot_physics.py` 正向运动学到 JavaScript：`SEGMENTS`、`SERVO_NEUTRAL`、`SERVO_DIRECTION`、`poseToJointAngles`、`forwardKinematics`、`pointToPolygonDist`、平衡评分。
  - 16 舵机滑块面板，按右臂/左臂/右腿/左腿/未使用分组，显示原始值和物理角度。
  - 物理可视化：COM 质心红球 + 地面投影虚线、半透明支撑多边形、双脚指示环、0–100 平衡得分仪表。
  - `.rob` 文件加载与帧播放：ACT-40 二进制解析 + EYPT TEA-32 解密，逐帧浏览/自动循环，1/4x–4x 速度可调。
  - 7 组预设姿态一键切换：立正、军礼、展臂、捶胸、正步、伸手、大鹏展翅。
  - OrbitControls 视角控制，键盘快捷键（空格播放、← → 逐帧、R 重置），拖拽 .rob 文件加载。
  - 深色主题自适应 UI。

## 修复

- 支撑多边形坐标从 Python (+X=前, +Y=左) 到 Three.js (+X=右, +Z=前) 的映射中，脚长方向修正为 Z 轴（此前误置为 X 轴）。

## 验证

- Python 语法检查通过（`py_compile` 全部模块）。
- 4 个 EYPT 官方样本往返加解密逐字节一致。
