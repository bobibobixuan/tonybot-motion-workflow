# 0.6.0 — Tonybot Motion Studio 架构升级

## 变更

- **项目定位升级**：从「Tonybot Motion Workflow 自动编舞工具链」升级为「Tonybot Motion Studio：AI 辅助动作创作工作台」。
  - 核心闭环重新定义为：需求 → AI/motion.json → 3D 预览 → 关键帧微调 → 安全审计 → 导出 .rob。
  - 根 README 标题、简介、适用场景、GitHub 描述全面更新。
- **四层架构定义**：
  - `motion-core`（核心层）：rob_reverse / rob_crypto / tonybot_physics / rob_library
  - `motion-viewer`（预览层）：动作模拟器.html — Tonybot 3D 动作预览器
  - `motion-editor`（编辑层）：关键帧编辑器（规划中）
  - `motion-workflow`（工作流层）：dance_workflow / rob_compose / rob_safety
- **motion.json 格式规范**：新增 `12-motion-json格式规范.md`，定义可编辑动作工程格式，含完整 JSON schema、16 舵机 pose 映射、约束规则和完整示例。
- **架构规划文档**：新增 `11-Motion-Studio架构规划.md`，含项目新定位、目标用户和使用场景、motion.json 与 .rob 关系、三阶段路线图（格式标准化 → 编辑层 → AI 集成）。
- **文档体系重构**：
  - 预览器规范从 `11-3D动作预览器规范` 重编号为 `13-3D动作预览器规范`。
  - `文档/README.md` 阅读顺序扩展为 1–13。
  - `可视化模拟器/README.md` 补充 Motion Studio 预览层定位。
- **现有脚本行为不变**：rob_reverse.py、rob_crypto.py、rob_safety.py、dance_workflow.py 保持原有行为。
- **预览器无审计功能回归**：未重新加入 COM、支撑面、平衡分等安全审计模块。

## 原因

项目从单一逆向工程工具链升级为面向机器人舞蹈创作者的完整工作台。motion.json 作为核心交换格式，连接 AI 生成、手动编辑、3D 预览和 .rob 编译四个环节。
